# 회원 승인제 켜기 (무료 · 카드 등록 없음)

이 프로젝트(naro-biz)의 Firestore에는 **옛 시스템 데이터(tenants · users)와 그 규칙이 이미 있다.**
기존 규칙은 지우거나 바꾸지 않고, `access-block.rules` 블록만 **더한다.**

배포만 해서는 아무도 막히지 않는다(승인 블록이 없으면 지금처럼 모두 들어감). 블록을 게시하는 순간부터 승인제가 걸린다.

1. Firebase 콘솔 → naro-biz → Firestore Database → **규칙** 탭
2. 지금 규칙 전체를 메모장에 복사해 둔다(되돌리기용)
3. `match /databases/{database}/documents {` 줄 **바로 아래**에 `access-block.rules` 내용을 붙여 넣는다. 다른 줄은 손대지 않는다
4. **게시**
5. 사장님 계정(onlysh4sh@gmail.com)으로 로그인 → 왼쪽 메뉴 맨 아래 **사용자 승인**이 목록을 보여 주면 끝

- 이미 쓰고 있는 다른 계정은 다음 로그인 때 '승인 대기'에 멈추고 목록에 나타난다 → [승인].
- 승인제를 끄려면: 붙인 블록만 지우고 게시(2에서 복사해 둔 규칙으로 되돌리기).
- 무료 한도: 하루 읽기 5만 · 쓰기 2만. 로그인할 때 한두 번 읽는 정도.
