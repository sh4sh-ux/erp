# 회원 승인제 켜기 (무료 · 카드 등록 없음)

배포만 해도 앱은 지금처럼 동작한다(Firestore가 없으면 모두 들어감). 아래를 마치는 순간부터 승인제가 걸린다.

1. https://console.firebase.google.com → 프로젝트 **naro-biz** → 왼쪽 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치: **asia-northeast3 (서울)** → 다음
3. **프로덕션 모드에서 시작** → 만들기 (요금제는 그대로 Spark·무료)
4. 만들어지면 위 탭 **규칙** → 안의 내용을 모두 지우고 `firestore.rules` 내용을 그대로 붙여 넣기 → **게시**
5. 확인: NARO Biz에 사장님 계정(onlysh4sh@gmail.com)으로 로그인 → 왼쪽 메뉴 **설정 → 사용자 승인**이 열리면 끝

- 이미 쓰고 있는 다른 계정이 있으면, 다음 로그인 때 '승인 대기'에 멈추고 사용자 승인 목록에 나타난다 → [승인].
- 무료 한도: 하루 읽기 5만 · 쓰기 2만. 로그인할 때 한두 번 읽는 정도라 한도에 닿지 않는다.
- 승인제를 끄려면: Firestore 데이터베이스를 삭제하면 다시 모두 들어간다(각자의 업무 데이터는 Drive·Dropbox에 있어 영향 없음).
