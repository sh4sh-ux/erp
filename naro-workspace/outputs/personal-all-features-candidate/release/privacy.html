THE EDIT (디에디트)

개인정보처리방침

THE EDIT (디에디트)는 NARO Biz의 계정 인증, 개인 클라우드 기반 업무 관리 및 고객지원을 위해 아래 정보를 처리합니다.

1. 처리 항목과 목적

계정 생성·로그인·이메일 인증·비밀번호 재설정에는 이메일 주소, 비밀번호 인증 정보, Firebase 계정 식별자와 인증 상태를 사용합니다. 인증 요청은 Firebase Authentication을 통해 처리합니다.

거래처, 품목, 견적, 입금·출금, 재고 이동, 자재 이동 및 설정은 업무 화면 표시·계산·저장에 사용합니다. 이용자가 입력한 담당자명, 연락처, 이메일, 주소 등이 포함될 수 있습니다. 업무에 필요한 정보만 입력해 주세요.

고객지원 요청 시 발신 이메일, 문의 내용과 이용자가 첨부한 정보를 처리합니다. 비밀번호, 인증 코드, OAuth 토큰 또는 불필요한 업무 원문을 보내지 마세요.

2. 개인 클라우드와 접근 권한

업무 파일은 이용자가 선택한 Google Drive 또는 Dropbox의 NARO Biz 저장공간에 저장되고 브라우저에서 읽고 처리됩니다. 이 업무 저장 경로는 Firestore를 ERP 업무 데이터 저장소로 사용하지 않습니다.

재연결 편의를 위해 마지막으로 연결을 완료한 저장소 종류(Google Drive 또는 Dropbox)를 NARO 계정별로 이 기기의 브라우저에 기억합니다. 이 설정에는 저장소 토큰, 비밀번호, 파일 내용이 포함되지 않습니다. 다른 저장소를 선택하거나 사이트 데이터를 삭제할 수 있습니다.

Google Drive 재연결 시 잘못된 계정의 파일을 여는 것을 방지하기 위해, 연결 계정 식별자를 NARO 계정별 해시값으로 변환하여 이 기기의 브라우저에 기억합니다. 계정 선택을 간소화하기 위해 실제 연결이 확인된 Google 이메일 주소도 해당 NARO 계정별로 이 브라우저에 기억하고, 재연결 때 Google에 로그인 힌트로 전달합니다. 기억값은 로그인 권한이 아니며 비밀번호·OAuth 토큰·파일 내용·계정 식별자 원문은 저장하지 않습니다. 다른 Google 계정 선택 시 기존 이메일 힌트를 사용하지 않으며, 새 계정 연결 확인 후 갱신합니다. 사이트 데이터 삭제로 제거할 수 있습니다. 힌트와 관계없이 실제 연결 계정을 확인하고, Google이 요구하는 추가 인증은 생략하지 않습니다.

Google Drive에는 drive.file 권한으로 앱이 생성하거나 이용자가 앱에 사용을 허용한 파일에 접근합니다. Dropbox는 전용 App Folder를 사용합니다. 파일 내용·식별 정보·변경 버전은 이용자가 실행한 읽기·저장·삭제 및 충돌 방지 기능에 사용합니다.

Google Drive·Dropbox access token은 브라우저 메모리에만 유지하며 localStorage에 저장하지 않습니다. 새 실행이나 토큰 만료 후 저장소 재연결이 필요할 수 있습니다. ‘로그인 상태 유지’를 선택한 경우에만 Firebase SDK가 NARO 로그인 인증 정보를 이 기기의 브라우저 저장소에 보관해 재방문 시 복원합니다. 비밀번호 자체는 저장하지 않으며, 로그아웃하면 저장된 로그인 인증 정보를 제거합니다. 공용 기기에서는 선택하지 마세요. 선택하지 않으면 NARO 로그인도 메모리에만 유지합니다.

3. 보관과 삭제

Firebase 계정 정보는 탈퇴 처리까지 보관합니다. 계정 탈퇴·개인정보 삭제는 sh4sh@nate.com으로 요청할 수 있으며, 본인 확인 후 처리합니다. 현재 앱에는 즉시 회원 탈퇴를 실행하는 버튼이 없습니다.

고객지원 문의 이력은 처리 완료 후 30일간 보관한 뒤 삭제합니다. 법령상 별도 보존 의무가 적용되는 경우 해당 근거와 필요한 범위를 확인하여 처리합니다.

개인 Drive/Dropbox 업무 파일은 NARO 계정 탈퇴로 자동 삭제하지 않습니다. 이용자가 해당 클라우드에서 직접 삭제하며, 공급자의 휴지통·복구·백업 정책이 적용될 수 있습니다.

4. 로그아웃과 권한 철회

로그아웃·앱 연결 종료는 실행 중인 인증·연결 상태를 종료합니다. 저장된 파일, Firebase 계정, 공급자 측 접근 승인을 모두 삭제하는 동작이 아닙니다.

Google 또는 Dropbox 계정의 연결 앱 관리에서 접근 승인을 철회할 수 있습니다. 권한 철회와 클라우드 파일 삭제는 별개입니다.

5. 외부 서비스와 처리 위치

Google의 Firebase Authentication은 미국에서 인증 정보를 처리합니다. 공식 안내에 따르면 보안용 IP 로그는 수 주간 보관하며, 계정 삭제 개시 후 관련 인증 정보는 운영·백업 시스템에서 180일 이내 제거됩니다. Firebase Hosting은 IP 주소를 웹 제공·부정 사용 방지에 이용하며 수개월간 보관할 수 있고 글로벌 인프라를 사용합니다. Firebase 처리 안내

Google Drive와 Dropbox는 이용자가 선택한 업무 파일 저장 서비스입니다. 파일 전송은 연결·읽기·저장 등 기능을 실행할 때 이루어집니다. 공급자에 따라 미국 등 국외에서 처리될 수 있습니다. 공급자 자체 처리와 보관·복구에는 각각의 정책이 적용됩니다. Google 개인정보처리방침 · Dropbox 개인정보처리방침

NARO 계정 삭제 완료와 외부 공급자의 로그·백업 제거 완료 시점은 다를 수 있습니다. 외부 서비스의 자체 보안·접속 로그까지 수집하지 않는다고 보장하지 않습니다.

계정 정보의 열람·정정·삭제 및 처리 관련 요청은 고객지원 이메일로 접수합니다. 요청 대상과 본인 여부를 확인한 뒤 처리 결과 또는 처리가 제한되는 사유를 안내합니다. 타인의 업무 정보에 대한 요청은 권한 확인이 필요할 수 있습니다.
