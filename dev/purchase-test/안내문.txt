NARO Biz 매입 기능 — 화면 시험 안내 (가짜 Dropbox)
===================================================
이 꾸러미는 진짜 Dropbox 대신 '가짜 Dropbox'로 움직입니다.
· Dropbox 로그인, 새 계정, 새 Chrome 프로필이 필요 없어요.
· 거래처·품목·재고·견적·입출금은 모두 '(시험)'이 붙은 가짜 데이터예요.
· 운영 Dropbox와 운영 데이터에는 접속하지 않아요(브라우저가 바깥 주소에 연결하지 못하게 막아 둠).
· 화면 맨 위 주황색 띠 '…가짜 Dropbox · 운영 데이터와 연결 안 됨'이 보이면 시험 화면이 맞아요.

■ 시작 (3단계)
 1) 압축을 풉니다.
 2) 폴더 안 '시작하기.command'를 더블클릭합니다.
    · 처음 한 번은 막힐 수 있어요 → 파일을 오른쪽 클릭 → [열기] → [열기].
    · 'Node.js가 필요해요'가 나오면 열리는 페이지에서 LTS를 설치한 뒤 다시 더블클릭.
 3) 브라우저에 두 탭이 열립니다.
    · http://localhost:4219        ← 매입 앱(시험할 화면)
    · http://localhost:4219/__fake ← 시험 도구(연결 끊기 등)
    앱 탭에서 [Dropbox로 계속하기]를 누르면 바로 들어갑니다(가짜라 Dropbox 창은 열리지 않아요).
 · 끝낼 때: 검은 창(터미널)을 닫거나 Ctrl+C. 다시 켜면 가짜 데이터가 처음 상태로 돌아가요.

■ 시험 항목 (✔ = 이렇게 되면 통과)
 A. 저장과 입고는 따로
    왼쪽 메뉴 '매입' → [매입 시작하기] → + 버튼 → 매입처 '(시험) 대한원단'
    품목 2줄((시험) 셰프복 BK·S 20개, BK·M 30개) → [저장]
    ✔ 재고 화면 숫자는 아직 그대로   ✔ 시험 도구 '파일' 목록에 purchases.json 이 생김
    [입고 처리] → '일부만' → S만 20개 → 확인
    ✔ 재고 화면에서 셰프복 BK·S가 20개 늘어남
 B. 입고 취소
    진행 탭 → 입고 기록 옆 ··· → 입고 취소
    ✔ 재고가 원래대로, 기록은 '취소됨'으로 남음
 C. 출금 · 중복 클릭
    [출금 기록] → 금액 넣고 확인 버튼을 빠르게 여러 번 클릭
    ✔ 입금·출금 화면에 출금이 딱 1건
 D. 반품
    [남은 수량 전체 입고] → 진행 탭 [반품] → 3개
    ✔ 재고 3개 줄고, 출금 카드의 '남은 금액'도 줄어듦
 E. 매입 취소
    입고가 남아 있을 때 하단 '더보기' → 매입 취소   ✔ '먼저 입고를 취소해야 해요' 안내
    입고를 모두 취소한 뒤 매입 취소   ✔ 상태 '취소'(출금이 있었다면 '돌려받음' 선택 시 환불 1건)
 F. 연결 끊김 · 응답 유실 (시험 도구 탭 사용)
    ① [연결 끊기] → 앱에서 저장(또는 입고 처리) → ✔ '연결을 확인한 뒤 다시 시도해 주세요'
       [연결 잇기] → 다시 누름 → ✔ 한 번만 저장
    ② [보내는 중 끊김 (저장 안 됨)] → 앱에서 저장 → ✔ 앱이 스스로 확인하고 한 번만 저장
    ③ [저장은 됐는데 응답 잃음] → 앱에서 저장 → ✔ 두 번 저장되지 않음(재고·기록이 한 번만)
       ※ '앞서 끊긴 저장을 먼저 확인해 반영했어요. 다시 눌러 주세요'가 나오면 한 번 더 누르면 됩니다.
 G. 두 탭(두 기기) 충돌
    앱 주소(localhost:4219)를 탭 2개로 열고, 둘 다 같은 매입 → 정보 탭
    탭1 비고 수정 → 저장 / 탭2 비고를 다르게 수정 → 저장
    ✔ 탭2에 '다른 기기에서 먼저 바뀌었어요' 안내, 탭1 내용이 남음(덮어쓰지 않음)
    두 탭에서 같은 매입 [입고 처리]를 거의 동시에 → ✔ 재고는 한 번만 늘어남
 H. 지금 운영 버전과 함께 쓰기
    http://localhost:4220 을 엽니다(지금 운영 버전 + 같은 가짜 데이터).
    ✔ 견적·재고·입금이 정상, 재고에 매입 입고분이 보임, 매입 메뉴는 없음(정상)
    운영 버전에서 견적 하나 저장 → 4219로 돌아가 새로고침 → ✔ 매입도 그대로 정상
 I. 폰 화면
    앱 탭에서 ⌥⌘I(개발자 도구) → ⌘⇧M(기기 모드) → 위쪽에서 iPhone 선택 → 새로고침
    A~E를 한 번 더 눌러 봅니다.

■ 처음부터 다시 하고 싶을 때
 시험 도구의 [가짜 데이터로 처음부터] → 앱 탭 새로고침.

■ 알아 둘 것
 · '설정 → 사용자 승인' 화면은 운영 서버에서 목록을 읽어 오는 화면이라 시험 모드에서는 비어 있거나
   오류가 보여요(접속을 막아 두었기 때문 — 정상).
 · 시험 기록은 이 컴퓨터의 시험 서버 안에만 있고, 끄면 사라집니다. 지울 파일이 따로 남지 않아요.

■ 결과 알려 주기
 A~I 항목마다 '통과' 또는 '문제'를 적고, 문제는 화면 캡처와 함께 보내 주세요.
