NARO Biz 매입 기능 — 시험용 Dropbox 검증 안내
=================================================
이 꾸러미는 '매입'이 들어간 개발 버전을 내 맥에서만 여는 것입니다(http://localhost:4219).
운영 사이트(naro-biz.web.app)와 운영 Dropbox는 바뀌지 않습니다.

■ 준비물 (처음 한 번)
 1) 시험용 Dropbox 계정: 운영과 다른 이메일로 무료 계정을 새로 만듭니다.
 2) Chrome 새 프로필 'NARO 시험': Chrome 오른쪽 위 사람 아이콘 → 추가.
    이 프로필에서는 dropbox.com에 '시험용 계정'으로만 로그인해 둡니다.
    (평소 프로필에서 하면 운영 Dropbox가 연결될 수 있어요 — 꼭 시험 프로필에서)
 3) Node.js: 터미널에서  node -v  입력. 숫자가 안 나오면 https://nodejs.org 에서 LTS 설치.

■ 시작
 1) 이 폴더를 '다운로드'에 풀어 둡니다.
 2) 터미널(응용 프로그램 → 유틸리티)에서
      cd ~/Downloads/naro-purchase-test
      node serve-test.mjs
    '매입 시험 서버: http://localhost:4219' 가 나오면 준비 끝(창은 켜 둡니다).
 3) 'NARO 시험' 프로필 Chrome에서  http://localhost:4219  를 엽니다.
 4) 평소 NARO 계정으로 로그인 → 저장소 Dropbox → Dropbox 화면 오른쪽 위 이메일이
    '시험용 계정'인지 확인하고 허용.
    ※ 'redirect_uri' 오류가 나면: Dropbox 개발자 콘솔 → NARO 앱 → Settings → Redirect URIs에
      http://localhost:4219/oauth/dropbox/callback 을 추가한 뒤 다시 시도.
 5) 시험 재료 등록: 거래처 1곳(구분 '매입'), 품목 1개(색상 2개·규격 2개 이상).
 6) 왼쪽 메뉴 '매입' → [매입 시작하기].

■ 시험 항목 (✔ = 이렇게 되면 통과)
 A. 저장과 입고는 따로
    + 버튼 → 품목 2줄 → [저장]
    ✔ Dropbox 웹 'NARO Biz/Data'에 purchases.json 이 생김
    ✔ 재고 화면 숫자는 아직 그대로
    [입고 처리] → '일부만' → 한 줄만 넣고 확인
    ✔ 재고 화면에서 그 수량만큼 늘어남
 B. 입고 취소
    진행 탭 → 입고 기록 옆 ··· → 입고 취소
    ✔ 재고가 원래대로, 기록은 지워지지 않고 '취소됨'
 C. 출금(줄 돈)
    [출금 기록] → 금액 넣고 확인 (확인 버튼을 빠르게 여러 번 눌러 보기)
    ✔ 입금·출금 화면에 출금이 딱 1건
 D. 반품
    전체 입고 → 진행 탭 [반품] → 3개
    ✔ 재고 3개 줄고, 출금 카드의 '남은 금액'도 줄어듦
 E. 매입 취소
    입고가 남아 있을 때 더보기 → 매입 취소  ✔ '먼저 입고를 취소해야 해요' 안내
    입고를 모두 취소한 뒤 매입 취소(돌려받음 선택)  ✔ 상태 '취소', 입금·출금에 환불 1건
 F. 저장 중 연결 끊김
    새 매입 저장 → [입고 처리] 창을 열어 둔 채
    ⌥⌘I(개발자 도구) → Network 탭 → 'No throttling'을 'Offline'으로 → [입고 확인]
    ✔ 창 안에 '연결을 확인한 뒤 다시 시도해 주세요' 안내, 버튼이 '다시 시도'로 바뀜
    ✔ 재고·입고 기록은 그대로(반쯤 저장된 것 없음)
    다시 'No throttling' → [다시 시도]
    ✔ 재고가 한 번만 늘어남(두 번 늘지 않음)
    ※ 저장 '도중'에 끊기는 경우는 앱을 다시 열 때 목록 위에 '마무리 안 된 입고 N건 [이어서 하기]'가
      뜹니다. 손으로 재현하기 어려워 자동 테스트로 확인해 두었어요(혹시 보이면 눌러서 마무리).
 G. 두 기기에서 같은 매입
    같은 주소를 탭 2개로 열고 둘 다 같은 매입을 엽니다.
    탭1: 정보 탭 비고 수정 → 저장 / 탭2: 비고를 다르게 수정 → 저장
    ✔ 탭2에 '다른 기기에서 먼저 바뀌었어요' 안내, 탭1 내용이 남음(덮어쓰지 않음)
    두 탭에서 같은 매입 [입고 처리]를 거의 동시에 확인
    ✔ 재고는 한 번만 늘어남
 H. 지금 운영 버전과 함께 쓰기(호환)
    같은 'NARO 시험' 프로필에서 https://naro-biz.web.app 을 열고 같은 시험 Dropbox 연결
    ✔ 견적·재고·입금이 정상, 재고에 매입 입고분이 보임, 매입 메뉴는 없음(정상)
    운영 버전에서 견적 하나 저장 → 다시 localhost로 와서 매입 열기  ✔ 둘 다 정상
 I. 폰 화면
    폰에서는 localhost를 열 수 없습니다. Chrome에서 ⌥⌘I → ⌘⇧M(기기 모드) → iPhone 크기로
    A~E를 한 번 더 눌러 봅니다.

■ 끝내기
 터미널에서 Ctrl+C. 시험용 Dropbox의 데이터는 운영과 상관없으니 그대로 둬도 됩니다.

■ 결과 알려 주기
 A~I 항목마다 '통과' 또는 '문제'를 적고, 문제는 화면 캡처와 함께 보내 주세요.

■ 하지 말 것
 - 운영 Dropbox 계정으로 localhost에 연결하지 마세요(승인 전 매입 파일이 운영 Dropbox에 생깁니다).
